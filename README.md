# BASS LAB — 7개 모듈·단계별 보기(v0.5.0)

베이스 학습·연습 관리 PWA임. 기타 앱 FRET LAB(leedg79/proto v2.6.0)의 구조(모듈 → 레벨 → 과제, 세션 규칙, 학습일지, 백업, 백킹 트랙)를 그대로 가져와 4현 베이스용으로 바꾸는 중임

## v0.5.0 (7개 모듈 · 모듈별/단계별 보기)

- 모듈 재정리(사용자 결정): 1 Notes(음 찾기) · 2 Time(박자 유지) · 3 Groove(장르별 그루브) · 4 Technique(준비 중) · 5 Chord Tones · Scales · 6 Slap(준비 중) · 7 Ear Lab
- 홈 보기 두 가지: 모듈별 보기 / 단계별 보기(입문·초보·초급·중급·고급). 단계별 보기는 각 모듈에서 그 단계에 맞는 과제·주제·클릭 방식을 모은 연습 세트. 누르면 주제·설정이 채워진 과제 화면으로 가고, 기록은 원래 모듈 과제로 쌓임
- 모든 리듬·그루브에 난이도(입문~고급) 태그, 과제 안에서는 쉬운 것부터
- Time: 4비트·8비트·16비트·셔플·셋잇단·혼합 레벨의 기본 리듬 세트(47개, 4비트 9개 새로). 클릭 방식(매 박 / 2·4박만 / 1박만 / 2마디에 한 번 / 2마디 듣고 2마디 무음 / 4마디 듣고 4마디 무음)을 모든 리듬에 적용, 세션 중에도 바꿈. 결과에 실제 템포·구간별 쏠림·재진입 오차
- Groove: 록·팝·디스코 / 모타운·힙합·R&B·펑크 / 레게·라틴 / 블루스·셔플(17개, 팝 근음–5음·레게 스테퍼·라틴 툼바오·셔플 2개 새로). 드럼이 마디째 빠지는 방식(2·4마디 드럼 없이)
- Chord Tones · Scales: Arpeggios A1~A4에 Scales S1~S3(펜타·메이저 계열·모드)를 같은 모듈 안 레벨로 합침

## v0.4.0 (Rhythm · 박자 우선)

- 우선순위 변경(사용자 결정): 베이스는 박자 준수·템포 유지가 가장 중요하고 그다음이 리듬 패턴. Rhythm을 홈 맨 앞에 두고, Scales는 메뉴에서 뺌(코드는 남김)
- R1 Time Keeping(박자·템포 유지): 개방 A를 4분·8분으로 계속 치는 동안 클릭을 줄임 — 2·4박만 / 1박만 / 2마디에 한 번 / 클릭 2마디·무음 2마디 / 클릭 4마디·무음 4마디 / 박 쪼개기 바꾸기(마디마다 4분 → 8분 → 셋잇단 → 16분). 8·16마디
  - 결과: 박에 맞춘 비율·평균 오차·±50ms 비율·쏠림에 더해 실제 연주 템포(BPM), 구간별(클릭 있음·없음) 평균 쏠림과 마디마다 빨라짐·느려짐(ms/마디), 클릭이 돌아올 때 첫 박 오차
- R2 Rhythm Patterns 36개: 8분 펌핑, 점음표(3+3+2 포함), 16분, 셔플·셋잇단, 싱코페이션, 쉼표·끊어 치기, 고스트 노트(x, 판정에서 선택), 당겨 치기·붙임줄. 근음(개방 A) 중심, 옥타브·5음 일부
- R3 Groove Lock 12개: 드럼 루프(킥·스네어·하이햇·라이드, 칸 표 표시) 위에서 킥 자리에 베이스 붙이기 — 록·팝·펑크·모타운·R&B 하프타임·레게 원 드롭·보사노바·블루스 셔플·디스코·힙합
- 두 방식: 판정(마이크·입력 장치로 어택 시점을 박과 비교, Technique 판정 엔진·박자 보정·감도·입력 장치 선택 그대로) / 판정 없이 같이 치기(클릭·드럼에 맞춰 끝까지, 시범 베이스 소리 켜기·끄기). 판정 통과 또는 끝까지 1번 = 통과 1회, 3회 = 완료 1회. 판정은 통과하면 BPM을 올리는 템포 사다리
- 악보: 고스트 노트는 x 머리·TAB X, 셔플은 표시

## v0.3.0 (Arpeggios)

- 새 모듈 Arpeggios(기타 앱의 Chords 자리). 코드 운지 대신 베이스가 치는 코드톤·아르페지오를 익힘
  - A1 Triads(메이저·마이너·디미니시드·어그먼티드·서스4), A2 7th Chords(maj7·7·m7·m7♭5·dim7·6·m6·m(maj7)): 아르페지오 찾기(근음 12개 = 1회), 코드 종류 바꾸기(근음 자리 그대로 C → Cm → Cdim, 바뀐 음 주황, 1순환 = 1회), 아르페지오 사전
  - A3 Inversions · 2 Octaves · 9th: 3음·5음·7음부터 치기(12문제 = 1회), 4번 줄 근음 2옥타브(6개 = 1회), 9th 아르페지오 찾기(R 3 5 7 R 9)
  - A4 Apply: 진행 위 코드톤 따라가기. 드럼·코드 반주(베이스 꺼짐)에 맞춰 마디마다 코드 모양과 박마다 칠 음(근음 4박 / 근음–5음 / 근음–5음–옥타브–5음 / 근음–3음–5음–3음 / 근음–3음–5음–7음 / 자유)을 노랗게 표시. 코드가 바뀔 때 손 이동이 가장 적은 자리. 진행 9가지, 2바퀴 = 1회
- 운지 규칙: 왼손 한 자리 4프렛(1손가락 1프렛), 줄은 같은 줄 위쪽이나 더 가는 줄로만, 개방현은 낮은 자리에서만, 1옥타브 모양은 자리 옮기기 없이 6프렛 안(4·3번 줄 시작, 모든 종류·근음 확인). 2옥타브는 한 자리에서 칠 수 있는 만큼 치고 위쪽 줄에서 옮김(높은 키는 20프렛까지)
- 정답 화면: 파란 선 = 운지 순서, 흐린 원 = 같은 자리의 다른 코드톤, "소리 듣기"로 올라갔다 내려오는 소리

## v0.2.0 (Scales)

- Scales 모듈을 4현용으로 옮김. 레벨(S1 펜타·블루스, S2 메이저·마이너, S3 모드, S4 코드톤)과 과제(모양 익히기, 근음 위치, 시작음 바꿔 치기, 모드 전환, 블록 연결, 코드 전환하며 익히기)는 기타 앱과 같음
- 블록(5개): 펜타토닉은 줄당 2음 박스(4줄 × 2음 = 8음, 약 1옥타브 반). 7음계·코드톤은 같은 박스의 프렛 범위(왼손 한 자리, 1손가락 1프렛) 안의 음. 4현은 범위가 좁아 하모닉·멜로딕 마이너의 7음처럼 빠지는 음이 생기면 범위 바로 바깥(±2프렛)의 가장 가까운 자리로 채움
  - 예: A 마이너 펜타 블록 1 = 4번 줄 5·8 / 3번 줄 5·7 / 2번 줄 5·7 / 1번 줄 5·7, C 메이저 블록 1 = 7 8 10 / 7 8 10 / 7 9 10 / 7 9 10
- 모드 포지션(7개): 줄당 3음(4줄 × 3음 = 12음)
- 블록 연결: 4현에 맞춰 슬라이드로 넘어가는 줄을 3·2번 줄 중심으로 바꿈. 코드톤은 블록에 음이 적어 블록 2개까지만 연결
- 시작음 바꿔 치기: 고른 구간 안에서 한 옥타브를 칠 수 없는 음(예: 0~4프렛의 개방 D)은 구간에 가장 가까운 자리에서 시작
- 코드 전환하며 익히기: 반주의 베이스 파트를 끄고 드럼·코드만 나옴

## v0.1.0 (기반 이식)

- 악기: 4현 표준 튜닝(1번 현 G2 · 2번 현 D2 · 3번 현 A1 · 4번 현 E1). 지판·스케일 지판·TAB을 4줄로 그림
- 악보: 낮은음자리표, 베이스 관례대로 실음보다 한 옥타브 높게 적음(개방 E = 덧줄 1개 아래 E)
- Notes: N1 무작위 2현, N2 전체 4현(0~15프렛). 정답은 "1번 현(G) 8프렛"처럼 줄 이름을 함께 표시
- Ear Lab: E1 음 이름(음역을 베이스 음역 E1~C4로, 기본 음색 베이스), E2 음정(C2~E4 중심, 기본 음색 베이스), E3 선율·화성·코드 청음. E4 프레이즈 채보는 베이스 라인이 생기면 추가
- 백킹 트랙: 베이스 파트 음량 기본값 0(내가 베이스를 맡음), 필요하면 올려서 따라 들음
- 같은 주소(leedg79.github.io)에 있는 FRET LAB과 기록·설정·캐시가 섞이지 않게 저장 이름을 basslab으로 분리. 백업 파일도 서로 복원되지 않음
- 앱 아이콘: 4줄 지판, 주황 점
